# DSH 企业版插件（dsh-enterprise）

## 解决了什么问题

公司统一部署了 DSH 网关（`dsh-enterprise-gateway`）之后，员工终端还有一堆事要自己搞定：填模型地址、配密钥、选默认模型——配错了就用不了，改了密码就要挨个修。更麻烦的是管理员对终端没有任何约束力：想强制登录、想禁用某个插件、想拦住敏感内容外发，都做不到。

这个插件装进员工 DSH 终端后，这些全部自动化：

- **员工只需登录一次** — 账号密码换网关令牌，模型列表、默认模型、凭证自动配置好，登录即可用；配置坏了可一键修复
- **终端始终与网关对齐** — 登录、修复、启动对账三条路保障终端模型列表与网关一致
- **策略可下发** — 网关下发的策略（心跳开关、插件管控、规则引擎）在终端自动生效，支持灰度与回执
- **插件管控** — 自动清理企业允许清单之外的插件，企业插件市场统一安装入口
- **未登录即阻断** — 可开启强制登录，不登录就不让用
- **敏感内容拦截** — URL 拦截与文本 DLP 规则在终端侧生效，有命中记录

## 安装

要求：DSH 终端 + 已部署的 `dsh-enterprise-gateway`

**方式一：从源码安装（开发机）**

```powershell
# 1. 构建（零依赖）
node build.mjs

# 2. 安装到 DSH
dsh plugin add file:./

# 3. 验证
node --test "test/*.test.mjs"
```

**方式二：登录即用（员工电脑）**

员工在 DSH 终端打开登录页 `/plugins/enterprise`，输入企业账号密码即可——插件自动完成全部模型配置，无需手动填任何地址或密钥。

## 与网关的配对

插件登录后通过网关的 `/auth/login` / `/v1/models` / `/policy/current` 等端点完成认证、模型配置与策略拉取，网关侧部署见 [`dsh-enterprise-gateway`](https://github.com/mafeis/dsh-enterprise-gateway) 仓库。
